# reicky 产品说明

## 一句话
给自己用的跨平台桌面便签：桌面上常驻一个小编辑器，随手贴文本、拖文件记路径，任何时候都能复制出来。

## 平台
macOS（含 Intel x86_64）/ Windows / Linux。不做移动端。界面适配各系统原生观感。

## MVP（v0.1）
- 默认只显示一个便签编辑窗口，记住位置和尺寸
- 纯文本，输入即自动保存
- 6 种颜色：黄、蓝、绿、粉、紫、灰
- 拖入文件/文件夹：只存路径引用，显示为小标签；单击打开，Alt/⌥+单击在文件管理器显示，× 移除引用
- 底部小按钮：
  - 颜色（弹层里也能切换语言 中文 / EN）
  - 变换形状：瘦高 → 宽扁 → 正方形 循环
  - 归档：归档当前笔记，主窗口换一张新的空白便签；已归档笔记可恢复
  - 笔记列表：从底部弹出，按修改时间倒序，滚动加载更多；分“笔记 / 已归档”；点一条在独立小窗口打开
- 笔记**不能删除**
- 多语言：中文、English，默认跟随系统
